# Features that could make Little Lives distinctive

Prioritize a few persistent everyday stories over a large menu of shallow actions. None of these features is implemented by this audit. Base dependencies are the approved house/characters, stable affordances, reservations, contact animation, event memory and save schema.

Complexity: S ~1–2 person-weeks, M ~3–6, L ~7–12, XL >12 after base systems exist; broad planning ranges, not quotes. Performance impact describes incremental runtime cost, not art production cost.

## Suggested first distinct experience

Deliver a rainy Sunday breakfast followed by Naomi reading to Laila, while Elias works on a personal project and Darius tidies the table. The player can stay in the full-house overview and still understand the story through lighting, room arrangement, movement and expressions. Save it midway and restore every participant, prop and shared task consistently. This combines existing cooking intent with room/family systems and a modest amount of excellent new content.

Use authored contextual conversation templates selected by recent events, participants and preferences first. Naturalness comes from timing, turn-taking, shared attention and matching expressions; unconstrained generated text alone does not supply those. Generative dialogue, neighborhoods, extensive growth and a pet should not delay the seven core approval gates.

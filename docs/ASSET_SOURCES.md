# ASSET SOURCES

Every shipped asset is generated by project code (see ASSET_MANIFEST.csv). **No third-party models, textures, sounds or animation libraries are used**, so there are no licences or attributions to track today, and no download links are listed.

The user-supplied design board is used only as visual reference; nothing from it is traced or embedded in the build.

If licensed assets are introduced later (e.g. mocap via a retargeting library, CC0 textures), each must be added here with: source URL (verified, not guessed), licence, commercial-use and modification rights, attribution text, and file format — before it enters the build.
